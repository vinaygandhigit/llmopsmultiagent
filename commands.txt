### Run API 
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

## Balance Enquiry
curl http://127.0.0.1:8000/account-agent/chat 
  -H "Content-Type: application/json" 
  -d '{"message":"What is the balance for account ACC10001?"}'
